# 🎬 CineManager — Frontend

> Modern cinema management and movie reservation platform built with **Angular**, providing a complete user and administration experience.

CineManager Frontend is the web application of the CineManager platform. It provides an intuitive interface for discovering movies, viewing screenings, making reservations, managing personal information and administering cinema operations.

---

## ✨ Features

### 🔐 Authentication & User Management

* User login
* User registration
* Role-based access
* User profile management
* Secure authentication

### 🎞️ Movie Experience

* Browse available movies
* Retrieve movie information from the backend API
* Upcoming movies
* Movie details
* Movie discovery interface

### 🎟️ Reservation System

* Select a movie and screening
* Select available seats
* Create a reservation
* Reservation summary
* Reservation history
* View upcoming reservations
* Manage reservations

### 🏢 Cinema Management

* Cinema rooms
* Room information
* Seat availability
* Cinema genres

### 👥 Administration

* Admin dashboard
* User management
* Movie management
* Genre management
* Cinema room management
* Reservation management
* Complete reservation list

## 🔑 Role-Based Access

The application provides different experiences and permissions depending on the authenticated user's role.

* **User:** Movies, screenings, reservations, history and profile
* **Admin:** Dashboard, users, movies, rooms, genres and reservations

# ⚙️ Installation

## Prerequisites

* Node.js
* npm
* Angular CLI

## Clone the Repository

```bash
git clone https://github.com/mChaabi/Cinema_FrontEnd.git
cd Cinema_FrontEnd
```

## Install Dependencies

```bash
npm install
```

## Run the Application

```bash
ng serve
```

The application will be available at:

```text
http://localhost:4200
```

---

# 🔗 Backend API

This frontend communicates with the CineManager REST API developed with **Java 21 / Spring Boot**.

**Backend Repository:**

https://github.com/mChaabi/Cinema_Project

Make sure the backend API is running before using the application.
